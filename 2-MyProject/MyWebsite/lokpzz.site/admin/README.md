# ZYYO 后台管理系统

## 🚀 快速开始

### 访问后台
```
直接访问：admin/dashboard.html
```

### 功能列表
- 📊 项目管理
- 🏷️ 标签管理  
- ⏰ 时间线管理
- ℹ️ 个人信息（头像、背景、职业）
- ⚡ 技能墙管理
- 📊 GitHub 图表集成
- 🔗 社交链接管理
- ⚙️ 系统设置

## 💡 使用说明

1. 打开 `dashboard.html`
2. 无需登录，直接进入后台
3. 可视化管理所有内容
4. 数据保存在 localStorage
5. 刷新前台查看效果
